# Contributing

Keep changes small, source-faithful, and reviewable.

- Do not commit downloaded media, models, renders, cookies, or credentials.
- Preserve source URLs, metadata, checksums, and exact acquisition commands.
- Explain candidate rejection and boundary decisions rather than deleting the
  reasoning.
- Run `python scripts/validate_project.py .` before proposing changes.
- Do not describe third-party material as public domain without explicit proof.
- Do not add a historical claim to host narration without a fact-check entry.

When contributing code, keep topic-specific information in YAML configuration
or project documents instead of hardcoding it into scripts.
